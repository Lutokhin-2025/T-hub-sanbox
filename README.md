Загрузка данных о международных аэропортах из публичного JSON API через библиотеку requests.
Создание базы данных PostgreSQL внутри контейнера Docker и заполнение таблицы ~6700 записями с помощью SQLAlchemy.
Нормализация данных и приведение типов столбцов с использованием pandas.
Генерация визуального отчёта (таблицы первых 20 аэропортов) в виде изображения (PNG) с помощью matplotlib.
Запуск всего стека приложения и базы данных одной командой через Docker Compose.
